# 视觉技术路线与数据流

本文档梳理 2026 规则下人形机器人视觉系统的完整技术路径与数据流，
覆盖四个核心视觉输出、图卡识别双路径、控制链路、数据生成与训练链路、
GPU 加速版结构。

代码位置：`jetson/`（CPU 版主线）、`jetson/gpu_vision/`（GPU 加速版）。

---

## 1. 系统总览

```
USB 相机 1280×720 (VFOV 55.876°, 俯角 45°, 高 32.5cm)
    │
    ├─► 巡线管线 (line_detector_v1_warp.py)
    │     IPM 鸟瞰 → 二值化 → 带扫描 → 误差融合 → fused_err
    │     ├─ 输出① 转向+偏角 (fused_err / angle_err)
    │     ├─ 输出② 红条距离 (原图判红 + 精确反投影)
    │     └─ 输出③ 窄门信号 (宽度差分 + 红条/起跑线双验证)
    │
    └─► 图卡管线 (shape_detector.py)
          找框 → 单应矫正 200×200 → 纯CV 规则分类
          └─ 输出④ 图形类别 → 动作号 1-6

控制输出：协议 V2 LINE_CTRL 10Hz → 主控步态（run_robot.py）
```

| # | 视觉输出 | 实现 |
|---|---|---|
| ① | 转向 + 偏角 | `line_detector_v1_warp.py::process()` |
| ② | 红条距离 | `line_detector_v1_warp.py::_detect_red_bar()` |
| ③ | 窄门信号 | `line_detector_v1_warp.py`（窄门状态机） |
| ④ | 图卡类别 | `shape_detector.py::update()` |

## 2. 巡线管线数据流

```
1280×720 BGR 原图
  │
  ├─[IPM] warpPerspective(M) ────────────► 320×400 鸟瞰 (z=20~80cm)
  │                                        cm_per_px≈0.332, z_per_px≈0.150
  │
  ├─[灰度] max(max(R,G,B), BGR2GRAY) ────► 320×400 灰度
  │
  ├─[二值化链] blackhat(椭圆31×31)
  │            → adaptiveThreshold(GAUSSIAN, 31, C=-8)
  │            → threshold(black_th)      black_th = median(adaptive掩码) + (-2)，限幅[25,80]
  │            → close5 → open5 → close5 → open3
  │            → 连通域过滤(面积<300 或 高<80 删除)
  │            ─────────────────────────► binary_clean（线=白）
  │
  ├─[带扫描] low band y=350-399 (z≈20-27cm)  ┐ 逐行 run 检测
  │          mid band y=300-349 (z≈27-35cm)  ┘ 配对求中线
  │          + bottom lock（y≥350 对称性验证）
  │          + 统一 heading 加权最小二乘拟合 → 物理角度
  │            ─────────────────────────► near_err / far_err / angle_err / curve_slope
  │
  └─[误差融合] fused_err = w1·near + w2·lookahead + w3·curve + w4·angle
                ────────────────────────► 输出① 转向+偏角
```

关键参数（`line_follow_params.json`）：带位置/权重、bottom lock 增益、
融合系数、PID（直道/弯道双模式）、丢线恢复。

### 2.1 红条距离（输出②）

```
1280×720 原图
  │
  ├─[判红] R≥105 且 R>G+28 且 R>B+28 ─────► 红像素掩码
  │        红像素 <50 → 未检出
  │
  ├─[取近边] v_foot = 红像素最低行（离机器人最近的边）
  │
  └─[精确反投影] a = (v_foot − cy) / fy
                 z = h·(cosθ − a·sinθ) / (a·cosθ + sinθ)
                 h=32.5cm, θ=45°, fy=679.2, cy=360
                 ───────────────────────► 输出② 红条距离 (cm)

横向: x_cm = (cx_red − cx) / fx × z
```

- 绕开 IPM（避免 clamp 扭曲与质心误差），闭环模拟 35/60/80/100cm 误差 ≤0.1cm
- 有效测距上限 ~100cm（原图视野内）；红条规格 10mm×20mm 截面木条

### 2.2 窄门（输出③）

```
进入条件：宽度比例 out 模式 + 红条可见 + 起跑线可见（三重确认）
离开条件：红条距离 < 35cm 或 起跑线距离 < 50cm
几何布局：窄门出口 ─24cm─► 红条 ─36cm─► 起跑线(60cm)
```

## 3. 图卡识别管线数据流（输出④）

```
任意分辨率 BGR
  │
  ├─[归一化] resize → 960×540（参数标定基准），quad 坐标映射回原图
  │
  ├─[S1 线宽选择性二值化]
  │     blackhat(椭圆9×9) → adaptive(GAUSSIAN, 31, C=-12)
  │     → close3 → 各向异性 close(1×5, 5×1)
  │     → 笔画宽过滤（CC 内 DT 中位半径×2 ∈ [1.0, 7.0]px，拒 2cm 巡线）
  │     → 细长度过滤（小 CC 面积<60 且长宽比<2 删除，拒圆斑污渍）
  │     ────────────────────────────► 二值图（线=白）
  │
  ├─[S2 候选生成] 四通道并行
  │     Hough 双族（横/竖族极值线组合，topk=4）
  │     LSD 线段补短边盲区
  │     角点 4 环（交点链闭合四边形）
  │     CC 四边形（连通域外接）
  │
  ├─[S3 验证] _geom_ok 纯数值预筛（过滤数百候选 → 数十）
  │     → _refine_quad 逐边 ±8px 精调
  │     → _verify_quad 采样验证（闭合度 / 线宽 DT / 环内含量）
  │     → 帧间 IoU 跟踪加分 → 最优 quad
  │
  ├─[矫正] _warp_card：角点排序 → 外扩 4px → 内缩 14%（外框环不进 warp）
  │     → 单应变换 → 200×200 正视图（INTER_NEAREST）
  │
  └─[分类] 纯CV：close5+dilate 桥接断笔画 → 最大轮廓
           → 几何判定树 → 类别
           （Hu 矩 matchShapes 距离作辅助信息，不参与判定）
        → 确认状态机（连续 3 帧同类别 + 冷却 3200ms）→ 动作号 1-6
```

### 3.1 纯 CV 判定树（`_classify_contour`）

特征提取：

| 特征 | 方法 |
|---|---|
| 顶点数 | `approxPolyDP` 粗 ε=0.035×周长 |
| 凹顶点数 | 细 ε=0.02，逐顶点叉积与环绕方向比对 |
| 圆形度 | 轮廓点到质心距离的变异系数 cv_dist |
| 形状比 | `minAreaRect` 填充率 fill_rect + 角度 ang |

判定顺序：

```
凹顶点 ≥3（凹形）: fill_rect<0.42 → 十字
                  | 凹顶点≥5 → 五角星
                  | fill_rect<0.60 → 十字
                  | 否则 → 五角星
凸形: 顶点==3 → 三角形
     | ang≥25° → 菱形
     | fill_rect≥0.84 → 正方形
     | cv_dist<0.13 → 圆形
     | 否则 → 三角形
```

**Hu 矩辅助说明**：`cv2.matchShapes` 与 6 类模板比对距离输出到 `dbg["hu_dist"]`，
仅作参考。原因：Hu 矩对旋转不变 → 正方形与菱形（45° 旋转关系）理论同距，
无法单独区分；且对透视/压扁不鲁棒。方向信息（`minAreaRect` 角度）是
判定树的关键补充。

### 3.2 动作映射

| 图形 | 动作号 | 动作 |
|---|---|---|
| 圆形 | 1 | 举左手 |
| 五角星 | 2 | 举右手 |
| 正方形 | 3 | 抬左腿 |
| 菱形 | 4 | 抬右腿 |
| 十字形 | 5 | 举双手 |
| 三角形 | 6 | 摇头 |

识别确认后机器人**完全停止步行 3 秒**做动作（`run_robot.py` 图卡状态机）。

## 4. 控制链路数据流

```
视觉 10Hz
  │
  ├─[一步前瞻] eff_err = fused_err + PREVIEW_GAIN · STEP_LEN_CM · sin(ang)
  │            弯道时提前加大指令，补偿双足一步之内的切线漂移
  │
  ├─[PID] 直道/弯道双模式 → 连续纠偏量 steer (cm)
  │
  ├─[量化] route_u8 (1=go 2=left 3=right 4=slight_left)
  │        ex_mm_i16 (预测步末横向偏差, 10mm 档)
  │        ang_cdeg_i16 (航向误差, 1° 档)
  │
  └─[协议 V2] LINE_CTRL (0x02, 10Hz) + HEARTBEAT (0x01, 10Hz)
              帧: 0x55 0xAA VER MSG FLAGS SEQ TS_MS(4) LEN PAYLOAD CRC16(2)
              CRC-16/CCITT-FALSE (poly=0x1021)
              主控契约：迈步前取最近 1 帧；lost=1 或 conf<35 → 不前推
```

主控按 ex/ang 决定转向力度（route 只管方向），若 300ms 无有效包 → SAFE_STOP。

## 5. 数据生成

```
6_pictures/generate_synthetic_cards.py（闭环合成）
  │
  ├─[场景合成] 标准卡渲染 → 随机 scale/旋转/压扁/透视 → 白底带污渍场景
  │
  ├─[闭环找框] 真实 ShapeDetector 找框 → 预测 quad
  │
  ├─[矫正] _warp_card → 200×200（黑底白线）
  │
  └─[质量闸] 白占比≤50% + 图形质心居中<15px（过滤找框不准样本）
```

Hu 矩模板生成：`jetson/make_hu_templates.py` 走同一闭环管线取
6 类轮廓 → `shape_hu_templates.npz`。

## 6. GPU 加速版结构（`jetson/gpu_vision/`）

```
backend.py
  HAS_CUDA = cv2.cuda.getCudaEnabledDeviceCount() > 0
  ├─ 可用 → cv2.cuda 链（整链一次上传 → 多算子 → 一次下载）
  └─ 不可用 → 纯 CPU 回退（与原 CPU 版逐算子等价，本地验证即验证逻辑）

  shape_binary_chain : blackhat → adaptive → close3 → aniso close（960×540）
  line_binary_chain  : blackhat → adaptive → threshold → close5/open5/close5/open3
                       （black_th 中位数修正 + Otsu 回退链内等价）
  warp_perspective   : 找框候选矫正 / IPM 鸟瞰
```

- 几何算法（Hough/LSD/轮廓/连通域）留 CPU：CUDA 无对应实现或收益小
- 目标硬件：Jetson Orin Nano Super 8GB（Ampere 1024 CUDA 核，JetPack 7.2）
- 验收工具：`probe.py`（环境/计时）、`compare_cpu_gpu.py`（双版本一致性）
