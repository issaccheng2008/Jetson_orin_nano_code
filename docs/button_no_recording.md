# 按钮启动：无记录模式

在板子的 `config/button_start.env` 加一行：

```bash
NO_RECORDING=1
```

下次按钮启动时生效。旧配置未写该项时默认 `0`，保持原有记录方式。改回 `NO_RECORDING=0` 即恢复记录。可以先执行 `bash scripts/run_button_vision.sh --dry-run`：无记录配置下，命令应包含 `--no-recording`，且不包含 `--recording-root`。

开启后，按钮启动的视觉程序不创建逐帧日志、丢线截图、图卡截图、视频或测试目录；自动启动的主程序不创建主程序日志、`main_live.log`、电机/IMU CSV 或控制诊断日志，也不启动 `tee`；视觉和 connector 服务的标准输出及错误输出送往 `/dev/null`。已有记录保留，不会删除。启动态仍使用临时的就绪信号文件进行进程握手，退出时清除；它不是运行记录。

本开关只控制这套按钮启动链路。手动启动视觉或主程序时，可分别传入 `--no-recording`；如果终端命令自己带有 `| tee ...`、重定向到文件或另起录像脚本，需要同时去掉这些外部记录命令。系统自身的服务生命周期和内核日志不由本参数控制。
