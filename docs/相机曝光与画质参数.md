# 相机曝光与画质参数

按钮启动每次打开摄像头后，可以自动设置曝光等硬件参数，并读取实际值核对。配置位于 `config/button_start.env`，不需要每次手动执行 v4l2 命令。未填写的值/keep 不写入驱动，保留摄像头当时的状态；keep 不会恢复出厂或恢复自动曝光。

## 固定手动曝光 5 ms

```bash
CAMERA_EXPOSURE_MODE=manual
CAMERA_EXPOSURE_MS=5
```

毫秒数是 5，不是 v4l2 原始数值 50。程序自动换算成驱动单位（100 微秒），先关闭自动曝光，确认成功后再设置曝光时间。当前摄像头范围 3～2047，即 0.3～204.7 ms，以 0.1 ms 为步长；其他相机以驱动公布的范围为准。

要试 3 ms，把值改成 3；要试 10 ms，改成 10。缩短曝光可以减少运动拖影，但可能使画面变暗。先只改曝光，在同样灯光下比较赛道边缘与图卡识别；亮度参数不能补回短曝光丢失的光子。

恢复自动曝光时同时清空手动时间：

```bash
CAMERA_EXPOSURE_MODE=auto
CAMERA_EXPOSURE_MS=''
```

既不切换模式也不设置曝光：

```bash
CAMERA_EXPOSURE_MODE=keep
CAMERA_EXPOSURE_MS=''
```

## 其他可选参数

以下范围来自你提供的摄像头控制表，不适用于所有型号。程序会查询实际设备后检查 min/max/step；空字符串表示不修改，数字 0 表示明确设置为 0。

| 配置项 | 你这台相机的范围 | 用途 |
|---|---|---|
| CAMERA_BRIGHTNESS | -64～64；原值 0 | 调整图像亮度 |
| CAMERA_CONTRAST | 0～95；原值 2 | 明暗对比度 |
| CAMERA_SATURATION | 0～100；原值 75 | 颜色饱和度 |
| CAMERA_SHARPNESS | 1～7；原值 2 | 边缘锐化；不能恢复运动拖影中的细节 |
| CAMERA_WHITE_BALANCE_MODE | keep / auto / manual | 白平衡模式 |
| CAMERA_WHITE_BALANCE_K | 手动模式时 2800～6500 | 色温，单位 K |
| CAMERA_POWER_LINE_HZ | 50 / 60 / 0 | 灯光抗闪烁频率；0 关闭，不是摄像头帧率 |

可添加下列项，保持为空时不会改变画质：

```bash
CAMERA_BRIGHTNESS=''
CAMERA_CONTRAST=''
CAMERA_SATURATION=''
CAMERA_SHARPNESS=''
CAMERA_WHITE_BALANCE_MODE=keep
CAMERA_WHITE_BALANCE_K=''
CAMERA_POWER_LINE_HZ=''
```

固定白平衡示例：

```bash
CAMERA_WHITE_BALANCE_MODE=manual
CAMERA_WHITE_BALANCE_K=4600
```

恢复自动白平衡：模式改为 auto，同时把 CAMERA_WHITE_BALANCE_K 清空。不要一次改所有画质参数，尤其亮度/对比度变化可能影响现有二值化和图卡判断。

## 更新、重启与确认

```bash
cd ~/jetson_orin_code
git pull --ff-only
bash scripts/run_button_vision.sh --dry-run
sudo systemctl restart humanoid-button-vision.service
sudo journalctl -u humanoid-button-vision.service -b -n 100 --no-pager
```

查找 `[camera-controls]`，手动 5 ms 应出现：

```text
auto_exposure requested=1: actual=1
exposure_time_absolute requested=50: actual=50 (5 ms)
```

同时可直接检查：

```bash
v4l2-ctl -d /dev/video0 --get-ctrl=auto_exposure,exposure_time_absolute
```

设置只在启动时执行，不占每帧处理循环。重启服务、重插相机后再启动，都会按配置重新应用。录像帧率、相机曝光和视觉输出频率是不同参数。

该功能使用 Linux V4L2 与 v4l2-ctl。工具缺失时安装 `sudo apt install v4l-utils`。控制项不支持、范围不符、设置失败或读回不一致会打印原因，不会假报成功；`vision/run_.../run_manifest.json` 的 camera_controls 保存 requested/actual/error 和汇总状态 applied/partial/unavailable/unchanged。失败不会中断步态启动，仍需在日志确认实际曝光是否符合预期。成功写入的其他项目不会因某一项失败而自动回滚。

手动命令对应参数例如 `--camera-exposure-mode manual --camera-exposure-ms 5 --camera-sharpness 2`。Windows 上保留原相机打开方式，硬件调节仅在 Linux 启用；留空配置不会访问这些控制项。

单位参考：[Linux Camera Control Reference](https://www.kernel.org/doc/html/latest/userspace-api/media/v4l/ext-ctrls-camera.html)。
