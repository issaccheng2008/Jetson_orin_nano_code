## 1. 详细日志：下一趟可以回答哪些问题

终端C的main及跨棍入口默认额外生成独立的诊断CSV和manifest，保留原电机CSV格式。记录每周期实际执行的同一条裁剪链：

```text
raw_action → raw_target_policy → absolute_target_policy
           → slew_target_policy → final_target_policy → motor_send_argument
```

每级独立clip_mask、上一最终目标、真实dt、窗口实际参考q、回传q/qd、收到状态的序号/时间戳/主机接收时间、观测与命令、当前模型/任务阶段、是否使用held参考、发送结果均同一行关联。固定帧、站直hold、phase等待不会伪装成模型推理。

**received_q是STM32包里的位置，可能已经被下位机裁剪或冻结，不是未经处理的编码器真值。** motor_send_argument是串口发送函数的实际参数，不等于STM32已执行确认。固件SHA无法从现协议取得，manifest明确unknown。

manifest包含实际参数、关节映射、模型/相关源码SHA、初始状态和旧日志关联。诊断目录采用UUID独立文件名，避免覆盖；CSV缓冲写，每50行flush，关闭时flush，不保证断电保留最后缓冲数据，也未在Jetson上测过额外I/O开销。

终端C可给原命令追加：

```bash
--diagnostic-log-dir records/control_diagnostics
```

不写时，main默认放原position日志目录下的control_diagnostics；phase放原CSV所在目录下的control_diagnostics。`--no-control-diagnostics`显式关闭。具体列与测试见 [详细裁剪日志说明](详细裁剪日志说明.md)。

## 2. 视觉P1落实内容

### 可信度与横偏拆开

- 底部候选使用配对扫描覆盖、跨行宽度一致性和拟合残差评价；偏离中心超过24px不再直接判无效。
- 实际扫描行作配对比例分母，少量成功行不能把覆盖率报成100%。
- 不可信/关闭的底锁融合权重为0，也不进入heading或强制曲线模式。
- 同一质量规则应用到near候选，防止被底锁拒绝后又从band路径参与控制。
- 单边只能依靠最近1秒内至少两帧可信双边宽度支持，质量最多0.35，不提供heading/preview；重复单边不能自行产生可信宽度。

### 近场与前瞻分别输出

```text
near_error_cm：道心在画面右侧为正
preview_error_cm = clip(0.5 × (far_error_cm − near_error_cm), −5cm, +5cm)
控制原始误差 = −near_error_cm − preview_error_cm
```

preview需要可信双边近/远观测，目标距离为近远采样距离的中间值。heading独立输出，并标heading_valid和拟合残差；没有再把heading、curve等多份描述重复叠加。near为0时可靠preview仍可非零；大横偏也不会被有界preview任意抵消。

`--anticipation-clip`仅兼容旧命令，不再影响P1融合，启动横幅会提示。旧angle/curve融合增益不再参与主融合；离散输出仍默认0/+0.5，fire/stop/turn/gap参数本批未重新定值。

### 时间滤波与过期处理

- 正常时间常数0.18秒，抖动档0.25秒，更新率 `1-exp(-dt/tau)`。
- 质量>=0.20才能接受测量；不把低质量变成超长平滑。滤波历史存厘米值，动态比例尺不会重新解释旧数值。
- 超过0.25秒未接受测量后标stale，控制器清掉旧输出与过期转向；下一可信测量重新初始化滤波。
- process接收实际dt；旧调用不传时使用单调时钟。停车snapshot恢复跟踪记忆和接受时间，但不回滚观测时钟，因此停车诊断不能把旧行走EMA伪装成新鲜。
- 红条、起跑线、窄门事件在巡线无效时继续独立更新。

这些默认值是当前实现的可审查起点，未据实车闭环证明最优。构造器可通过 `config={'vision': {'p1': {...}}}`设置有单位的参数；当前终端入口使用默认值，不存在对应全部P1参数的CLI。

## 3. 视觉逐帧记录

终端B给原命令追加：

```bash
--line-log-dir records/line_telemetry --dump-on-loss records/loss_dump
```

每run保存 `run_manifest.json` 与 `line_frames.jsonl`。记录每帧near/preview/heading、各有效性、measurement_age、bottom权重、dt、最终vx/wz、turn/gap剩余时间、门控/图卡事件和相机姿态。完整图像仍由loss dump保存，逐帧文本不塞入图像数组。两目录的run_id相同可关联。

本选项默认关闭；主机详细裁剪日志默认开启。两进程的主机时间可用于近似对齐，未新增曝光硬件时间戳，不能宣称曝光与关节状态已经严格同步。
