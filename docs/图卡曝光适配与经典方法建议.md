## 现有图像管线的曝光敏感处

图卡原图使用标准 BGR2GRAY；巡线使用最大颜色通道灰度，两者的亮度响应不同。白平衡改变通道比例，并不等同于曝光整体降低。当前相机示例默认 keep，新增控制接口本身不意味着已改变相机画面。

| 环节 | 当前做法 | 曝光降低时的影响 |
|---|---|---|
| 模糊 cue 提取黑环 | black-hat核31；响应>12；闭运算核9 | 弱边框可能在形成候选前就被删掉 |
| 模糊 cue 亮孔 | 亮孔均值>=100；亮孔与环差>=4 | 暗但完整的真卡可能直接被拒绝 |
| 模糊 cue 分数 | 亮孔占比×灰度差；本次门槛1.2 | 同一结构分数随灰度差改变；旧背景分布不可直接套到新曝光 |
| 精准找框主通道 | black-hat核9；Gaussian局部阈值，窗口31、C=-16 | 固定16灰度余量不会随局部对比度缩小 |
| 精准找框 ring通道 | 原始灰度Gaussian模糊+全局Otsu+闭运算 | 理想增益变化较能适应，局部阴影或反光可能破坏统一阈值 |
| 精准分类 | 整理外框、映射200×200，使用 binary与ink并集 | 前面丢失笔画或补出错误连接，仍会改变分类形状 |
| 巡线 | 自适应候选之后还有25～80全局阈值及连通域筛选 | 只调图卡C或cue分数无法改善这一条管线 |

例如所有灰度乘0.25后，8位图的最高亮度不超过63.75，亮孔>=100这一条件必定无法通过。相机变暗不能简单用降低最终cue分数补偿。

短曝光能降低运动模糊，但可能降低信噪比；增加增益能提亮也会带来噪声。灰度方差下降可能来自噪声减少，也可能来自对比度压缩，需要分别检查。饱和反光和严重运动模糊已丢掉的信息不能靠阈值恢复。

## 建议一：局部背景归一化，优先对照

这是光照校正/背景估计的常用思路。针对白地板、白纸和黑色笔画，可以沿用现有形态学背景估计，比较相对暗度：

```text
B = 灰度图的局部背景估计（例如较大核的形态学闭运算）
relative_dark = (B - gray) / max(B, noise_floor)
```

对理想乘性亮度变化，分子分母共同缩放，比固定 black-hat>12 更稳定。这是根据成像简化模型提出的方案，尚未验证本项目实车效果；伽马、通道增益、截断和传感器噪声会破坏理想不变性。

具体改动建议：

1. 黑环候选新增相对暗度对照通道，先不替换现有通道。
2. 亮孔改为结合相对亮度、孔/环相对对比度及噪声质量检查。不要单独删除>=100条件；在暗处噪声也会被放大。
3. cue分数另记录相对对比度版本，例如 `inner_frac*(cg-sg)/max(cg,noise_floor)`，其阈值重新校准，不能继续使用原单位的1.2。
4. 保留孔占比、环厚、尺寸、切边、跨帧确认和接近过程约束。背景归一化不会自动区分真卡与地板形成的假环。

背景核应大于要保留的笔画宽度，又避免把大块背景纹理当作细线。可依据预期卡框像素尺寸及运动模糊宽度选少数几个尺度，避免无上限地扩大候选通道。

## 建议二：Sauvola／Wolf，适合作为阴影下的二值化对照

经典局部二值化方法会结合局部均值和标准差；OpenCV ximgproc 提供 Niblack、Sauvola、Wolf 和 NICK。[官方接口](https://docs.opencv.org/4.13.0/df/d2d/group__ximgproc.html)

Sauvola 的阈值为：

```text
T = local_mean * (1 + k * (local_std / R - 1))
暗笔画 = gray <= T
```

因此比固定 `local_mean-C` 多考虑了局部对比度。[OpenCV 实现](https://github.com/opencv/opencv_contrib/blob/4.x/modules/ximgproc/src/niblack_thresholding.cpp)

建议先放在原始图卡灰度或经过背景校正的灰度上，作为现有 ring/Otsu 通道的对照；不要把适用于暗笔画的公式直接照搬到“线已经变亮”的black-hat响应上。它仍有窗口、k、R等参数，并不对所有曝光变化自动不变；低对比度、噪声和反光区域仍可能出现假墨迹。Wolf使用更广的图像统计，计算范围应限制在有效区域，避免远处背景改变统计。

部署前检查 Jetson 是否有 cv2.ximgproc。普通 OpenCV 包不一定带 contrib 模块；可在离线环境先比较，或用 boxFilter/sqrBoxFilter 计算局部均值与标准差，避免为了单个函数改变生产依赖。

## 建议三：CLAHE，作为辅助增强

CLAHE在局部块内增强对比度，并通过裁剪直方图限制过度放大。它适合暗区与亮区同时存在的画面；噪声也可能被增强，裁剪限制只能缓解。[OpenCV 官方说明](https://docs.opencv.org/4.13.0/d5/daf/tutorial_py_histogram_equalization.html)

可从低强度设置做对照，例如官方示例的clipLimit=2.0、tileGridSize=(8,8)，这不是本项目已经确定的最佳值。尽量只处理有效地面区域或卡片候选区域，保留原始图用于几何和诊断。增强后黑线宽度及连接关系可能改变，不能简单沿用全部旧阈值并断言准确率提高。

优先级低于背景归一化及局部阈值对照；不建议把CLAHE、自动伽马、动态C、自动白平衡全部串起来，避免多个自适应环节同时改变证据。

## 白平衡和相机控制建议

白底黑线主要依赖明暗差，优先保证地面区域不过曝、暗线有信噪比、运动模糊可接受。场地光照稳定时，先调好相机再固定曝光与白平衡；不需要为了灰度识别再额外逐帧软件白平衡。

Gray-world是经典白平衡方法，假设场景各通道均值应趋于灰色；OpenCV实现还能排除高饱和像素。[官方说明](https://docs.opencv.org/4.13.0/d7/d71/classcv_1_1xphoto_1_1GrayworldWB.html) 对本场景的推断是：若用全画面估计，彩色背景可能影响结果；白纸/地板中的未饱和区域更适合作为中性参考。应慢速更新或调好后固定，避免每帧增益变化导致cue证据断续。

红色等颜色检测要另查HSV阈值；软件白平衡或通道归一化可能改变颜色，不宜让图卡灰度增强图替代所有模块的原图。

## 如何验证和决定是否替换

先固定一套相机设置，用同一批原始图做以下离线对照：现有管线、背景归一化、Sauvola／Wolf、低强度CLAHE。保持其他几何和状态机条件一致。每段序列单独初始化检测器，不能将不同图片或方法的跨帧历史混用。

需要覆盖真卡从远处接近、反光地板无卡、六类卡停稳后的精准分类。给候选框标注是否落在真实图卡上，统计确认位置/距离、漏触发、误触发、跨类错误及处理耗时；更多候选不等于更高准确率。

建议记录每个候选的孔均值、环均值、灰度差、相对差、孔占比、拒绝原因、阈值、候选位置及确认状态。并保存原图、black-hat、候选墨迹、最终warp，才能判断被哪一级过滤。
