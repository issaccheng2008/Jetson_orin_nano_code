# 手机 / 电脑双摇杆遥控设计

日期：2026-10-02

状态：用户已确认实现；首版在同一 Wi-Fi / 手机热点内使用，并要求精致的 UI。

## 目标与方案选择

在 Jetson 上运行遥控网页服务，手机和电脑通过浏览器访问 Jetson 的局域网 IP。
左摇杆控制前进线速度 vx，右摇杆控制偏航角速度 wz；vy 始终为零。

可选方案：

1. **局域网网页（采用）**：手机、电脑共用界面，不需要安装客户端、域名或云服务器。
2. 原生手机与桌面软件：需要分别安装和维护，当前两个控制量不足以体现额外成本的收益。
3. 公网域名入口：需要解决 Jetson 可达性、身份认证和传输加密；首版无需配置，后续按需求扩展。

## 已核对的现有接口

- `humanoid_jetson_deploy/command_source.py` 接收 UDP JSON，命令范围为 vx=0..1 m/s、wz=-0.5..0.5 rad/s，vy 强制为 0。
- `main.py` 的 walking 模式使用 49 维观测，接收 vx / wz，不支持后退和横移。
- 现有 UDP 指令超时默认 0.25 秒，过期后向策略提供全零速度。
- `connector.py` 已有速度变化率限制的实现，可复用其数学逻辑。
- 现有 UDP 输入只传命令，没有向发送者返回电机、实际速度或策略运行状态。
- ONNX 推理及 STM32 串口仍由现有上位机负责；网页服务不打开串口。

## 架构

```text
手机触屏 / 电脑鼠标与键盘
        ↓ 同源 HTTP 页面和命令 API
Jetson 遥控服务（鉴权、单控制者、指令超时、限速、平滑）
        ↓ 本机 UDP JSON，50 Hz，默认 127.0.0.1:5007
main.py --command-source remote
        ↓ 现有 walking 策略 / USB 串口
STM32
```

网页使用本地 HTML、CSS、JavaScript，运行时不依赖外部字体、CDN 或互联网。
服务采用 Python 标准库 HTTP 服务与独立发布线程，降低 Jetson 的安装成本。
客户端每约 50 ms 发送当前输入，同一时刻仅允许一个普通运动请求在途，避免堆积。
停止请求允许优先发出；服务端使用会话和序号拒绝停止之前的延迟运动请求。
发布线程独立以 50 Hz 更新本机 UDP 输出，网页请求不阻塞策略推理。

新增独立 `remote` 命令源选项；默认使用 5007，与视觉模式的 5005 分离。
仍允许通过已有参数显式指定 UDP 端口，但文档明确遥控、视觉不可同时向同一端口发送。
remote 模式只用于 walking；拒绝与固定关节帧、one-foot 策略、视觉卡片动作模型组合。

## 操作与显示

- 左摇杆单轴向上推：从 0 增加到选定的前进速度上限；向下拖不会产生负速度。
- 右摇杆单轴左右推：左转为正 wz，右转为负 wz。提供启动配置翻转转向符号，以便实机核对。
- 两个摇杆支持两指同时操作；松开一个摇杆仅将对应通道目标归零，另一个仍按输入控制。
- 初始前进速度上限为 0.4 m/s，转向上限为 0.5 rad/s。服务端强制限制，界面无法越过配置上限。
- 电脑支持 W / 上方向键前进，A、D / 左右方向键转向；松键归零，空格停止。输入框内打字不触发行走。
- 点击“启用控制”后才接受运动输入；初始状态、重新加载、断连恢复后都保持未启用。
- 提供清晰的“停止”按钮：撤销控制会话并发送全零速度；再次移动必须重新启用。
- 页面失焦、切到后台、触摸取消、页面退出时清空输入，并请求停止；服务端超时保护不依赖浏览器能否成功发送最后一包。
- 界面支持手机横屏、竖屏和桌面；采用高对比度仪表样式、大触摸区域、清晰的中文标签。
- 显示浏览器与遥控服务的连接状态、目标 vx / wz、服务端当前发布的指令和请求延迟。
- 明确这些数值是命令值；收到 HTTP 响应或发出 UDP 不代表机器人已执行，界面不得显示虚构的电机状态或实际速度。

## 控制与异常处理

### 控制权和访问

服务启动时生成随机访问口令，操作者在页面输入后连接；允许通过启动配置指定口令。
口令不放在访问 URL 中，也不保存到浏览器持久存储。页面与 API 同源，不开放跨域控制。
同一时刻仅一个会话取得控制权，其余设备提示被占用；不能自动抢占正在控制的设备。
使用新的控制会话时先从零输入开始，不能沿用上一会话的指令。
首版 HTTP 入口用于可信局域网，不直接部署到公网。

### 限速、失联和停止

- 正常输入通过线速度、角速度限幅和变化率限制，避免向步态策略突然给出大幅指令变化。
- 默认变化率沿用当前 connector 的尺度：vx 为 1 m/s²，wz 为 2 rad/s²；允许在服务启动时配置。
- 松手时目标立即归零，正常输出按变化率限制下降；页面需区分目标值和发布值。
- 浏览器命令连续 0.3 秒未更新：撤销控制会话，下一发布周期发送全零命令；过期会话的迟到请求不能恢复移动。
- “停止”、失焦或后台停止立即将发布值归零，不等待平滑减速；同时清除会话，防止旧请求恢复移动。
- 遥控服务退出时尽力发送多包零指令；进程异常结束仍由上位机现有 0.25 秒 UDP 超时兜底。
- 校验 JSON、大小、类型、数值有限性、序号、口令和会话；无效请求不能刷新运动心跳。
- 客户端请求异常后清空输入、退出启用状态，并显示连接异常；恢复后需要人工重新启用。

这里的“停止”指将 vx / wz 命令归零；它不等同于电机断电急停，也不承诺机器人瞬间静止或保持平衡。
现有 STM32 急停、上位机状态检查与电机启用流程保持有效，网页不远程开启电机。

## 交付与验证

1. 控制状态测试覆盖限速、非法值、两轴输入、单控制者、过期和迟到请求、停止后重新启用。
2. 本地 HTTP + UDP 测试验证摇杆命令到接收端的数据，并覆盖服务失联、超时归零和鉴权失败。
3. 回归验证固定速度、视觉、固定关节帧和 one-foot 模式的参数行为。
4. 浏览器验证桌面 / 手机尺寸、多指输入、键盘释放、后台停止、连接状态和布局。
5. 提供不连接电机的命令接收演示方法，以及 Jetson 上两个终端的正式启动步骤。
6. 真机步态、转向符号、无线延迟和停止行为需要在 Jetson / 机器人上验证；本地模拟通过不冒充实机测试。

首版不增加视频传输、云服务或原生 App；后续可以在同一网页控制架构上扩展。
