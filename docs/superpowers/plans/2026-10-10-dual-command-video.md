# 视觉目标与实际指令双箭头

需求：当前 policy49flitter 的视频同时绘制视觉目标方向和经过步态最短保持后实际发送所对应的目标方向。

实现：复用姿态 UDP 5007，在发送关节目标后反馈模型实际使用的速度、模式、串口写入状态、发送时间。通常 10 Hz，变化立即发。接收实际指令不做低通，超过半秒或未收到反馈显示未知。录像左右分栏、失线均红色，停车显示 STOP；视频索引保存两条指令及时间。保持控制/下位机协议不变。

验证：先验证实际保持与立即停车，再验证真 UDP 接收、未知/过期/旧版兼容、双箭头反向及索引快照、实际入口传递；运行视觉和步态回归，并检查预览和代码审查。

结果：497 项视觉相关测试、174 项步态测试通过。验证覆盖半秒内视觉与模型指令不同、停车提前打断、直立接管、旧姿态包兼容、相机暂停时录像补帧的实际反馈过期，以及录像索引的双指令快照。Windows 测试使用 Python UTF-8 模式读取仓库的 UTF-8 配置。独立审查发现的补帧过期问题已修复并通过回归；尚未实机测试。
