# 首卡启动指令序列

目标：将原来固定 1 秒直行做成独立可调参数，默认缩短为半秒；支持任意多段 duration_s/VX/WZ 组合，结束后仍执行已锁存首卡一次。保持普通巡线、图卡投票、模型和协议不变。

实现：独立标准库 startup_sequence.py 解析和验证 JSON、逐段推进；入口只在首卡 pending 且启动已放行时取序列命令。下一段在真正选中时重新计时，避免慢帧跳过。按钮脚本透传 JSON，CLI 在硬件打开前校验，日志/录像保留实际 publish 值。非空 JSON 优先于单段直行时长；未锁存首卡时沿用正常启动。
