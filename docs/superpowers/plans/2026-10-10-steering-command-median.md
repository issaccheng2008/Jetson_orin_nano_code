# 转向命令窗口实施记录

用户指定：0.5 秒内全部映射后转向输出取中位数；忽略每条丢线输出；偶数样本选择上/下中位数可配置；整窗丢线沿用原补偿；无历史备用角速度可配置。

实施步骤：
1. 写纯窗口单元测试，确认尚无窗口模块时失败。
2. 加入不重叠时间窗口、离散上下中位数、全丢线补偿与停止重置。
3. 接入视觉逐帧发布点，自动关闭策略的重复保持。
4. 接入备用角速度配置、方向上限、CLI 和按钮配置模板。
5. 验证真实入口发布、旧配置默认值、脚本传参、视频开关、门控/图卡停止、完整测试与 Bash 语法。
6. 将修改接到当前 policy49flitter 提交之后，复验并推送。

设计边界：保留当前图像算法、几何滤波与映射；窗口只统计最终逐帧 WZ。第一条命令和停止/明确启动动作立即生效。连接器心跳继续逐帧发布同一保持值。
