# 丢线补偿与强滤波

本次优先顺序：丢线决策、强滤波、有效视觉方向回退。上位机分支 `policy49flitter`，下位机不需要改固件。所有比较是同一批原始观测的离线指令回放，尚未验证实机轨迹。

## 改变后的行为

以前超过 LOST_HOLD_S 或几何过期，就清零 WZ 并继续 vx 前进。新的 history-stop 模式在丢失有效几何时，从最近0.8秒有效控制中保留近期转向，默认最多保持0.8秒；历史无转向、历史太旧或超过期限时，vx/wz 一起置零。不会根据配置的 VX 从停止状态凭空起步。直行偏置不算转向依据。

这不是推算出“实机新的偏差角”，而是短时沿用已有指令。最后仍在有效转弯时优先保持最后指令；最后一帧是普通直行时，使用按时间与新近程度加权的历史转向。边界保护、回归赛道或预测刹车明确否决的转向会从历史中清除。起跑门控、首卡动作、人工停止、无效时钟也清除历史。

仍看得清赛道并判断应直行时允许 WZ=0。新策略改变的是**缺少可信几何时的默认行为**。因为无效帧很多，连续失去几何超过0.8秒时会出现停车；这是退出无依据运动的设计结果。

## 强滤波 robust

新算法依次执行：最近三个有效样本的时间窗中值、固定低通、角度变化率限制。默认时间窗0.6秒、低通时间常数0.45秒、变化率上限45°/s。第一条有效角直接初始化；停机或超时停止后重新初始化。无效帧不会补零参与计算。

方向来源切换时不直接跳回新原始角；短时缺帧也不会通过一个很大的 dt 放开滤波。robust 模式的预测趋势用滤波值计算，防止原始尖峰绕过滤波再次影响 WZ；近边界的原始位置两帧保护继续保留。

代价是转向响应会变慢。强滤波不是越强越好：太迟可能仍会外侧出界。保持低通、角度变化率和最终档位的调整接口，One Euro、EMA、none 和 legacy 仍可选。

## 视觉回退

不把少于6个点、只有约1cm跨度的全局拟合硬改为有效。全局方向不可信时，segments 模式允许使用新鲜、成对的近段拟合方向，但仍要求宽度26～44cm、至少5点、至少4cm跨度、残差不超过2.5cm、近端锚点差不超过6cm。远段目标仍要经过段间连续性及三帧确认。

日志新增 `near_observation_paired`、`near_observation_quality` 和 `heading_control_reject_reason`。后者区分无点、点数不足、跨度不足、像素拟合残差、地面坐标异常等。全局偏差角的有效标志不会因为回退而被伪造；实际控制方向来源见 `steering_heading_source`。

## Jetson 操作

确认当前在 policy49flitter，然后更新。已有 config 不会被覆盖；以下追加设置在 Bash 读取时覆盖之前同名项：

```bash
cd ~/jetson_orin_code
git pull --ff-only
cat >> config/button_start.env <<'EOF'

# Strong filter + bounded loss recovery
STEERING_FILTER_MODE=active
STEERING_FILTER_ALGORITHM=robust
STEERING_FILTER_ROBUST_TAU_S=0.45
STEERING_FILTER_ROBUST_WINDOW_S=0.6
STEERING_FILTER_ROBUST_SLEW_DEG_S=45
STEERING_LOSS_MODE=history-stop
STEERING_LOSS_MAX_S=0.8
STEERING_LOSS_HISTORY_S=0.8
STEERING_SEGMENT_FALLBACK=1
EOF
bash scripts/run_button_vision.sh --dry-run
sudo systemctl restart humanoid-button-vision.service
sudo journalctl -u humanoid-button-vision.service -f -o cat
```

启动日志会显示 robust 参数、loss 模式、保持期限和分段回退是否启用。原有 KP/KD、步幅、模型、指令最短保持时间、WZ档位、相机参数均不需要因这项改动而调整。持续丢线后停车不等于程序退出；新鲜合格观测恢复后可重新行走。

## 调参和回滚

先保持以上默认值完成一组可对照测试。若响应明显太迟，减小 tau（例如0.35），或提高 slew（例如60）；若角度仍抖，先加大 tau，不延长丢线保持。`STEERING_LOSS_MAX_S=0` 会在缺少几何时立即停止。此模式下旧的 LOST_HOLD_S 不决定丢线转向保持期限。

每次只更改一类设置。要完全回到此次改动前的控制行为，在配置最后添加：

```bash
STEERING_FILTER_ALGORITHM=one-euro
STEERING_LOSS_MODE=legacy
STEERING_SEGMENT_FALLBACK=0
```

保留原来的 active/legacy 模式值以及 One Euro 参数，然后重启视觉。旧安装配置缺少 filter mode 时仍默认 legacy；新示例配置启用 active+robust。丢线新模式默认启用，安装配置可显式覆盖。

## 已有三次数据的验证

基准控制器对三次日志回放的指令差异均为0。相邻有效方向、相同几何来源、间隔不超过0.5秒的角度变化率95分位值如下（单位°/s；不是轨迹误差）：

| 测试 | 原One Euro | 新robust+丢线策略 |
|---|---:|---:|
| 10:52:40 | 237.6 | 40.9 |
| 10:54:12 | 84.5 | 24.7 |
| 10:55:31 | 142.2 | 44.5 |

新策略对这些观测分别产生35、4、23个历史转向帧及45、26、25个丢线停止帧。这些次数不等于新的实机运行结果。旧日志没有新增近段配对诊断，不能据此证明视觉回退增加了多少有效帧；此部分已有合成赛道和拒绝低质量输入的测试，需要新实机记录验证。

完整视觉测试368项通过。额外复核覆盖丢线超时、外部停止、指令保持、直行偏置、边界保护和低质量近段拒绝；没有剩余的已发现缺陷。
