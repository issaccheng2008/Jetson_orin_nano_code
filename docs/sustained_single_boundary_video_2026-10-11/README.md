[单边接管原图拼图](single_frames.jpg)列出全部 14 帧。目视可见相应的真实胶带边界；有些帧原图也能看见另一条线，但它在当前候选二值/逐行追踪中未达到可信条件，所以输出的是“单边有效”，不是声称原画面只有一条线。第 120～160 帧等明显离开场地的画面被拒绝属于合理结果。此图可以复核边界身份是否明显错配，不能据此计算漏检率，因为 541 帧没有逐帧人工真值。

合成地面几何和真实检测器入口的持续 5～8 秒单边、宽度与身份拒绝、法向圆弧及控制器接管测试见 `tests/test_sustained_boundary.py`。录像回放补充了压缩、光照、姿态变化下的连续过程，但**尚未实机验证**单边接管后的实际转向与出界风险。

2026-10-11 的实车记录中，可信右单边且继续前进的 38 帧仅输出左转 `+0.25`（27 帧）或 `+0.3`（11 帧）；原来成功的丢线搜索配置是 `STEERING_LOSS_FALLBACK_WZ=0.5`。现在右单边的几何控制已经要求左转时，使用这个配置值作为左转下限，仍受 `--wz-step`、`--max-wz` 限制。几何要求直行或右转时不强制左转；双边、左单边和真正丢线各走原路径。视觉端的 0.5 秒指令窗口仍会在切换时按有效帧求中位数，停车闸仍优先。这一调整尚未实机验证。
