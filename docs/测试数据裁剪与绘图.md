# 测试数据自动裁剪与绘图

程序完全离线运行，不连接摄像头、串口或机器人，也不改变原始记录。输入一次测试的目录，输出在该目录的 `analysis/` 中。可以在 Jetson 停止测试后处理，也可以把整个测试文件夹复制到电脑处理。

## 首次准备

切换到 `policy49flitter` 并更新后，**重新运行一次测试**。新记录会增加 `start_gate_mode`、`qr_passed`、`shape_passed`、`button_passed`、`start_released` 字段。

绘图环境需要 matplotlib，可在已有虚拟环境中安装：

```bash
cd ~/jetson_orin_code
source .venv/bin/activate
python -m pip install matplotlib
```

这只是离线程序的依赖，不需要修改机器人运行环境或自启动服务。

## 处理一次测试

更新代码后重启视觉，按按钮完成一次测试；测试结束停止视觉，让记录完成写入：

```bash
sudo systemctl restart humanoid-button-vision.service
# 按按钮并完成测试后：
sudo systemctl stop humanoid-button-vision.service
```

下次测试再次 `sudo systemctl start humanoid-button-vision.service`。

先找当天的测试目录：

```bash
ls -td records/tests/$(date +%F)/test_*
```

把下面路径替换为一次完整测试的文件夹；不要传入一天的大文件夹：

```bash
python scripts/analyze_recording.py records/tests/2026-10-09/test_实际目录名
```

默认规则：双阀 `both` 模式以首次同时记录到二维码阀1、首卡阀2已通过的帧为 T=0；先通过哪一个不影响结果。按钮 `button` 模式以按钮已按下且程序已放行为 T=0，不要求首卡或二维码。其他模式或未通过时明确报错，不用非零速度猜测启动。

双阀 T=0 表示启动条件满足，启动握手和等待期间的零指令也会保留；它不保证机器人这一瞬间已经迈步。时间精度受视觉帧采样频率限制。控制/IMU 从同一 Unix 时间起裁剪，控制第一帧可能稍晚于 T=0，不会强行移动两者时间线。

需要强制双阀规则时：

```bash
python scripts/analyze_recording.py records/tests/日期/test_目录 --gate-mode both
```

## 输出

| 文件 | 内容 |
|---|---|
| `steering.png` | 同一图：偏差角（左轴 °）、视觉 WZ、上位机实际模型输入 WZ（右轴 rad/s） |
| `imu.png` | 三个共用时间轴的子图：姿态、XYZ 角速度、XYZ 加速度 |
| `vision_after_start.csv` | 裁剪后的时间、偏差角及有效标志、视觉 vx/wz |
| `vision_after_start.jsonl` | 裁剪后的完整视觉记录，增加启动后时间 `t_s` |
| `control_after_start.csv` | 裁剪后的完整控制与 IMU 记录，增加 `t_s` |
| `summary.json` | 启动时间、判断依据、输入文件和裁剪前后条数 |

两条 WZ 使用阶梯线；无效偏差角断线显示，不当作零。图中不做额外滤波或重采样。模型 WZ 是指令，不是实机实际转速；IMU 角速度才是收到的测量数据。姿态由收到的四元数换算，偏航范围 ±180°；坐标约定沿用现有固件，不在分析中重新定义。

CSV 缺少执行 WZ、时间戳、四元数、加速度或陀螺仪列时会报错；单个样本的空值仍保留为曲线断点。

重复执行会更新 `analysis/` 的分析结果，不修改原始文件。请先停止该次测试再分析，避免读取仍在追加的记录。没有启动步态或没有控制 CSV 的测试无法生成这两张完整图。

## 旧数据

旧记录缺少结构化启动状态时，程序不会猜测。只有从日志确认了准确的 Unix 秒时间，才使用手动覆盖：

```bash
python scripts/analyze_recording.py 测试目录 --start-unix-s 1791463900.123
```

示例数字仅展示格式，必须替换为该次测试实际时间。手动覆盖会明确记录在 summary 中。旧视觉 JSONL 与对应 control CSV 也可复制到同一个独立文件夹进行处理；一份视觉文件、一个 control CSV 必须属于同一次测试。
